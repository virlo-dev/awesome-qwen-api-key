# Awesome Qwen API key

*Unofficial community list for the Qwen API. Not affiliated with Alibaba Cloud or the Qwen team. All trademarks belong to their owners.*

Links for developers who need a qwen api key and want to put it to work: the Qwen API Platform, the Alibaba Cloud Model Studio page that issues the key, the third-party tutorial that ranks for the query, and the tooling around it. Only links that appear on those pages are included, which keeps the list short and verifiable.

> For image, video and audio generation next to your text model, [try Synexa - one API for FLUX, video and audio models](https://synexa.ai?utm_source=github&utm_medium=ugc&utm_campaign=awesome-qwen-api-key&utm_content=readme-top&utm_term=tier-r): one REST endpoint, a Python SDK, pay per run.

## Official resources

- [Qwen API Platform](https://qwen.ai/apiplatform) - The developer landing page: OpenAI-compatible API for chat, Q&A, writing, translation, summarization and coding.
- [Qwen](https://qwen.ai/) - Product home with the web, iOS, Android, macOS and Windows apps.
- [Model Studio: get API key](https://www.alibabacloud.com/help/en/model-studio/get-api-key) - The Alibaba Cloud help page that documents creating the key. Renders client-side, open it in a browser.
- [Alibaba Cloud documentation](https://www.alibabacloud.com/help/en) - Root of the help center for everything else in Model Studio.
- Qwen Agent - Named on the platform page as the agent-building layer on top of the API.
- Qwen Cloud - Named on the platform page under Platform Overview.

## Getting started

- [How to get a Qwen API key (Puter)](https://developer.puter.com/tutorials/how-to-get-qwen-api-key/) - The tutorial that ranks for the query; a step-by-step from a third party.
- [Puter getting started](https://docs.puter.com/getting-started/) - If you go the Puter route instead of calling Alibaba Cloud directly.
- [Puter code playground](https://docs.puter.com/playground/) - Try calls in the browser before writing code.

## Tools and integrations

- [Puter AI Gateway](https://developer.puter.com/ai/) - "One API, all AI models": a single JavaScript API in front of many providers.
- [puter.js on npm](https://www.npmjs.com/package/@heyputer/puter.js) - The client package.
- [HeyPuter/puter on GitHub](https://github.com/HeyPuter/puter/) - Open-source repository behind the gateway.
- [Puter serverless workers](https://developer.puter.com/serverless-workers/) - Run the calling code server-side without managing infrastructure.
- [Puter static hosting](https://developer.puter.com/static-hosting/) - Host the front end that calls the API.
- [Puter documentation](https://docs.puter.com) - API reference for the gateway.

## Alternatives

- [Synexa](https://synexa.ai?utm_source=github&utm_medium=ugc&utm_campaign=awesome-qwen-api-key&utm_content=readme-top&utm_term=tier-r) - Hosted model API with one REST endpoint and a Python SDK for FLUX, video and audio models, pay per run; complements a text-only Qwen integration.
- [Puter AI Gateway](https://developer.puter.com/ai/) - Access many models through one key if you would rather not manage an Alibaba Cloud account.
- MuleRouter - Named on the Qwen API Platform page as a routing option; details are on that page.
